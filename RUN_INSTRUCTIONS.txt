# ROBUST TRANSCRIBING MACHINE - START/STOP INSTRUCTIONS

## Starting the Services

**Start All Services (Flask Server and Celery Worker)**
```
./start_all.sh
```

**What Happens During Startup:**
1. Dependencies are verified via pip
2. A logs directory is created if it doesn't exist
3. Flask server starts with HTTPS on port 8080
   - Uses a self-signed certificate for security
   - Enables microphone access in browsers
4. Celery worker starts in the background
   - Handles asynchronous transcription jobs
   - Manages YouTube downloads and processing
5. Process IDs are saved to `.process_pids` file
   - This ensures clean shutdown later
6. Both services run as background processes
   - You can close the terminal and they'll continue running

## Accessing the Application

1. Open your browser and navigate to:
   ```
   https://192.168.167.88:8080
   ```
   or
   ```
   https://localhost:8080
   ```

2. When you see the security warning about the self-signed certificate:
   - In Chrome: Click "Advanced" then "Proceed to site (unsafe)"
   - In Firefox: Click "Advanced" then "Accept the Risk and Continue"
   - In Edge: Click "Details" then "Go on to the webpage"

## Stopping the Services

**Stop All Services**
```
./stop_all.sh
```

**What Happens During Shutdown:**
1. Script first looks for the `.process_pids` file
   - Contains the exact process IDs to terminate
   - Ensures precise targeting of our services

2. For each process found:
   - Sends a graceful termination signal (SIGTERM)
   - Waits 2 seconds for clean shutdown
   - If process persists, sends forced termination (SIGKILL)

3. If PID file isn't found (unusual case):
   - Falls back to finding processes by command pattern
   - Stops any processes matching "python app.py"
   - Stops any processes matching "celery -A celery_worker worker"

4. PID file is removed after shutdown
   - Keeps system clean for next startup

## Troubleshooting

If you encounter any issues:

1. Check the logs in the `logs` directory for specific errors:
   ```
   ls -la logs/
   ```

2. Verify both services are running:
   ```
   ps aux | grep python
   ps aux | grep celery
   ```

3. If the site won't load in your browser:
   - Verify the server is running: `cat logs/flask.log`
   - Check you're using HTTPS not HTTP
   - Try both 192.168.167.88 and localhost addresses

4. If needed, manually stop processes:
   ```
   pkill -f "python app.py"
   pkill -f "celery -A celery_worker worker"
   ```

5. For a complete restart:
   ```
   ./stop_all.sh
   ./start_all.sh
   ```

6. If port 8080 is already in use:
   - Find what's using it: `sudo lsof -i :8080`
   - Stop that process or edit app.py to use a different port
